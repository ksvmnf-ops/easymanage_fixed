# EasyManage

تطبيق إدارة ومخزون مبني باستخدام Google Apps Script.

## الملفات

- `Code.gs`: منطق التطبيق والخدمات الخلفية.
- `index.html`: واجهة المستخدم.

## التشغيل

1. أنشئ مشروعًا جديدًا في Google Apps Script.
2. انسخ محتوى `Code.gs` و`index.html` إلى المشروع.
3. اربط المشروع بجدول بيانات Google Sheets وفق إعدادات التطبيق.
4. انشره كتطبيق ويب من إعدادات Google Apps Script.

> لا تُخزّن كلمات المرور أو مفاتيح الخدمة داخل المستودع. استخدم PropertiesService أو إعدادات النشر المناسبة.
